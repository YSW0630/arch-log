# Fix: `~/.bash_history` wont save after closing the terminal

## Cause (in my case)

**Insufficient permissions** on `.bash_history`

## Debug & Fix

```bash
$ ls -al ~/.bash_history 
-r-------- 1 pacfrog pacfrog 1237 Jul 11 00:49 .bash_history

$ chmod 600 ~/.bash_history

$ ls -al ~/.bash_history 
-rw------- 1 pacfrog pacfrog 1237 Jul 11 00:49 .bash_history

$ # Success: History is now saved correctly
```

## Bonus: Bash `Ctrl-r` (Reverse-i-search)

| Shortcut                  | Function                                |
| ------------------------- | --------------------------------------- |
| `Ctrl-r`                  | Start reverse search (`bck-i-search`)   |
| `Ctrl-g`                  | Abort search and restore prompt         |
| `Ctrl-j`                  | Edit the found command before executing |
| `Enter`                   | Run the selected command                |
| Press `Ctrl-r` repeatedly | Cycle backward through matches          |
