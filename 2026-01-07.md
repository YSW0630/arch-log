# Use GPG to sign git commit

Document how to use an existing or newly generated GPG key to make your commits on GitHub show as Verified.

```bash
gpg --full-generate-key
```

## 2. Make sure you already have a GPG Key

```bash
gpg --list-secret-keys --keyid-format=long
```

> It will display:

```bash
sec   ed25519/ABCD1234EFGH5678 2024-01-01 [SC]
      1234567890ABCDEF1234567890ABCDEF12345678
uid   Your Name <you@email.com>
ssb   ed25519/8765FEDC4321BA98 2024-01-01 [S]
```

Please remember one of the Key IDs (long), for example:

`ABCD1234EFGH5678 `

## 3. Exporting GPG Public Key

```bash
gpg --armor --export ABCD1234EFGH5678 
```

> you'll get a text:

```bash
-----BEGIN PGP PUBLIC KEY BLOCK-----
...
-----END PGP PUBLIC KEY BLOCK-----
```

copy it!

## 4. Add GPG Key to GitHub

`Settings → SSH and GPG keys → New GPG key`

Paste the public key you just copied then save

## 5. Test whether the signing was successful

```bash
# For this repository only
git config user.signingkey ABCD1234EFGH5678

# Global settings
git config --global user.signingkey ABCD1234EFGH5678

# If you don't want to add -S every time (git commit -S -m "xxx"), you can make the following settings.
git config commit.gpgsign true
git config --global commit.gpgsign true
```
