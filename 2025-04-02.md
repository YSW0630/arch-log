# Control Mouse Cursor in X11

## xev (X Event Viewer)

```bash
sudo apt install x11-utils
```

**TLDR:**

1. Captures and displays mouse movements, clicks, and keyboard presses.
2. Shows detailed information about events, including coordinates and button codes.
3. Useful for identifying key codes and button mappings.

**Typical Usage:**

```bash
xev
```

## xte (xautomation)

```bash
sudo apt install xautomation
```

**TLDR:**

1. Move the mouse to specified coordinates.
2. Perform mouse clicks and drags.
3. Simulate key presses and releases.
4. Automate GUI tasks in X11 environments.

**Typical Usage:**

```bash
xte 'mousemove 100 100' 'mouseclick 1'
```

## xdotool (Get Mouse Location)

```bash
sudo apt install xdotool
```

**TLDR:**

1. Get the current mouse coordinates in real-time.
2. Move the mouse to specific positions.
3. Click, drag, and scroll actions.
4. Automate keyboard inputs and window management.

**Typical Usage:**

```bash
# watch -n 0.1: update every 0.1 second
watch -n 0.1 xdotool getmouselocation
```
